# Request retries and native timers

The shared core previously retried a failed GET with its original credential after another operation completed sign-out or rotated the credential. Rejecting the eventual response did not prevent that transmission. Shared mobile preparation now captures an identity guard; canonical FAPI checks it before every fetch and before scheduling a retry. A change during backoff is checked again before transmission. The request keeps its first prepared headers, so it cannot acquire a new account credential for an old resource operation.

The packaged `NetworkFailureTest` covers sign-out, credential rotation and a transient network failure with an unchanged identity. The first two cases fail with no second transmission; the third completes with the same selected session after exactly one retry. Equivalent Apple packaged-engine tests cover these outcomes. A shared source test also changes identity during backoff and verifies that no further fetch occurs. This adds no independent native retry policy or request-signing middleware API.

The first Android run exposed a timer conversion defect: retry jitter supplies fractional millisecond values, while `AndroidCapabilities` parsed them as JSON integers. The timer effect failed and its callback never ran, leaving the retry unfinished. The adapter now reads a number, clamps it to the existing range and converts it to whole milliseconds for coroutine delay. Direct production-capability tests first failed with `NumberFormatException` at `1.75` and `10000.75`; they now verify successful completion and cancellation. Packaged, engine-proof and UI fixture timer adapters accept numeric durations too, and the token-refresh fixture compares its numeric delay window without integer parsing.

After fixing the timer, the old core reproduced both obsolete-retry failures on Android while its ordinary transient retry passed. The new core prevents the extra requests while preserving the rotated credential or signed-out state. An already transmitted request is not undone by this guard.
