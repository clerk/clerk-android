AppVersionSupportStatus

data class AppVersionSupportStatus(val isSupported: Boolean, val currentVersion: Long?, val minimumVersion: Long? = null, val updateUrl: String? = null)

Whether this build of your app meets the minimum version set for it in the Clerk Dashboard.

When the version is unsupported, Clerk rejects your app's requests until the user updates. The Clerk UI library shows its update-required screen over your app automatically; call com.clerk.api.ClerkConfigurationOptions.withUpdateRequiredViewDisabled to show your own UI instead.
