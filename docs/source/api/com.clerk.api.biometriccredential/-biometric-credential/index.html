BiometricCredential

@Serializable(with = BiometricCredentialSerializer::class)
data class BiometricCredential

A biometric credential associated with a user.

Biometric credentials allow users to sign in with device biometrics instead of their regular first factor. The private key used to sign server challenges never leaves the device.
